# Submission: project description

**Flaky or real? Let Drex decide.** CI pipelines make an unpriced bet every time a test fails: is it flaky, or is it a real bug? Frontier LLMs answer with a confident yes or no that carries no calibrated uncertainty, which gives you nothing to tune. We hand that decision to Drex. NDI (Nace Document Intelligence) extracts structured fields from raw CI failure logs: error type, test name, timing, infra signals, and retry history. Drex returns a calibrated P(flaky). A two-threshold policy turns that probability into QUARANTINE, RETRY, or BLOCK-and-alert. Human corrections then recalibrate the thresholds against an explicit cost table, where wrongly quarantining a real bug is the expensive mistake, so the decisions measurably improve without retraining or rewriting prompts.
