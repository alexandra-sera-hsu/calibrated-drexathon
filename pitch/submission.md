# Submission: project description

**Flaky or real? Let Drex decide.** CI pipelines make an unpriced bet every time a test fails: is it flaky, or is it a real bug? Frontier LLMs answer with a confident yes or no that carries no calibrated uncertainty, which gives you nothing to tune. We hand that decision to Drex. NDI (Nace Document Intelligence) extracts structured fields from raw CI failure logs: error type, test name, timing, infra signals, and retry history. Drex returns a calibrated P(flaky). A two-threshold policy turns that probability into QUARANTINE, RETRY, or BLOCK-and-alert. The loop runs as an Intern session, the Nace harness. Qwen3.8-27B on DeepInfra is System 2 and calls the extract, decide, act and feedback tools. Drex (drex-max-v1.1) is System 1: it supervised and guarded all 6 turns of the recorded run with 16 checks. Human corrections then recalibrate the thresholds against an explicit cost table, where wrongly quarantining a real bug is the expensive mistake, and the thresholds move only when the cost table says moving them lowers total cost. We benchmarked the loop against frontier open LLMs on DeepInfra (Llama-3.3-70B and DeepSeek-V3.2) on the same labeled failures. On 60 labeled failures (drex-max-v1.1, real API calls), Drex reached 96.7% accuracy versus 85.0% for Llama-3.3-70B and 88.3% for DeepSeek-V3.2, wrongly quarantined 0 real bugs versus 0 for both LLMs, and had lower expected cost (118 vs 228 and 210 eng-min, because the LLMs hedged with RETRY on 41 and 36 of 60 failures while Drex retried none) at 292 ms median latency (vs 2,456 and 1,618 ms) and about $0.07 per thousand decisions (vs $0.064 and $0.154). Every real regression scored P(flaky) ≤ 0.35, and 34 of 36 flaky failures scored ≥ 0.93. A 'retry passed ⇒ flaky' rule quarantined 2 real bugs that Drex blocked. In the learning step, 16 human labels changed 0 decisions. The refit kept the thresholds at 0.40/0.80, and forcing a fix for the one confident disagreement would have raised cost from 118 to 484, so the loop held. The opener was generated with Adobe Firefly and assembled in Adobe Express from our real Drex probability chart. Our takeaway: a verdict can't learn your costs, and a probability can.
